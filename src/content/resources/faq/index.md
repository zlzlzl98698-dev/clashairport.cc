## 二、购买选型核心避坑指南

### 1. 为什么“专线”和“中转”价格差了数倍？
- **普通公网中转（BGP 隧道）**：国内入口通过公网向海外中转服务器发包。白天速度尚可，但到了每晚 20:00–23:00 的晚高峰国际公网拥堵期，丢包率往往激增至 15%–30%，看视频频繁缓冲卡顿，且遇到特殊时期极易被大面积阻断。
- **物理专线（IEPL / IPLC）**：国内入口直连国际点对点专用物理光纤管道（不经过公网国际出口）。晚高峰丢包率几乎为 **0%**，延迟波动方差小于 2ms，具有绝对的物理抗封锁性与稳定性，因此带宽成本通常是公网中转的 3 至 5 倍。

### 2. 流媒体 4K 追剧与 AI 工具对节点的严苛要求
- **Netflix / Disney+ 解锁要求**：流媒体平台会维护全球商业数据中心 IP 黑名单。如果节点使用的是廉价公网机房 IP，打开 Netflix 只能观看其自制非版权剧目（Non-copyrighted content），无法搜索到各地区热播剧。只有采购了优质原生住宅 IP（Residential IP）或由专人维护流媒体 DNS 解锁池的节点，才能实现 4K 全区秒开。
- **OpenAI ChatGPT / Claude 访问要求**：大模型风控系统严格拦截数据中心机房 IP。优质机场会针对 OpenAI 域名配置专用分流组（Direct/Residential Proxy），确保注册、登录、绑卡会话始终分配在干净的原生 IP 池中。

## 五、日常选型与使用深度 FAQ

### Q1：为什么我的套餐还有 100GB 流量没用完，到了今天突然变成 0 了？
这是因为到达了你账户的**流量重置日（Reset Date）**。
在机场的常规按月订阅中，流量是“按月配给的使用权”，并非像手机话费一样永久存蓄。每个账单周期结束时，系统会自动清空上月剩余额度并赋予新周期的完整额度。若你的月度使用量极不稳定（如有时一个月用 200GB，有时两个月不用），强烈建议购买**不限时按量套餐**以避免浪费。

### Q2：我在家里用软路由拨号挂了代理，家里所有手机电视电脑都走代理，算几台在线设备？
**仅算 1 台在线设备！**
机场后台判定并发设备通常依据“向节点中转服务器发起 TCP 握手的公网 IP 数量”。当你的软路由作为全家网关时，局域网内部的所有设备流量均被软路由执行了 SNAT（源网络地址转换），汇聚成单一行走在专线上的 TCP 会话流，因此对机场端而言只占用一个设备名额。

### Q3：为什么购买后用了一天觉得不理想，提交工单申请退款却被客服直接拒绝？
因为几乎所有商业机场在服务条款（Terms of Service）中均有明确免责说明：跨境代理属于即时交付、激活后无法二次回收的数字虚拟商品。只要服务商没有遭遇长期整体瘫痪，商家均不支持“由于主观速度不满意”发起的无理由退款。这也是我们一再强调“**初次尝试务必买月付**”的核心原因。

### Q4：为什么同样是香港节点，有的节点看 YouTube 跑 10 万 Kbps，有的节点只有 5000 Kbps？
这取决于节点的**后端带宽容量与负载均衡权重**：
- 高速率节点通常分配在 1Gbps 或 10Gbps 的独享物理专线母机上，且当前在线人数未饱和；
- 低速率节点可能是低成本公网中转、或者该节点正被数名用户高并发下载大文件占满了带宽；
- 建议在客户端中将节点选择设置为“自动选择（URL-Test）”或“负载均衡（Load-Balance）”，由客户端自动将请求分流至当前延迟最低、吞吐最高的优质节点。

### Q5：机场订阅支持在多台设备上同时导入吗？
**完全支持导入，但不一定支持同时产生高并发流量**。
你可以将同一条订阅链接导入到你的 Windows 电脑、Mac 笔记本、iPhone 和 iPad 上。只要你不同时在这些设备上挂着代理高并发下载或跑满在线连接数，通常不会触发设备限制警告。
