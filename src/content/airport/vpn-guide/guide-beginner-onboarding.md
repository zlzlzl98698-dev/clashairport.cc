## 核心速览：翻墙基础概念“四大家族”通俗大白话 (Answer-First)

不要被任何高深的技术词汇吓退，翻墙的本质只需要搞懂以下四样东西的相互配合：

```
                    【科学上网四大基础概念通俗关系图】
                                     │
【机场 (服务商)】 ─────────────► 【节点 (海外服务器)】 ─────────────► 【订阅链接 (配置密码本)】
 相当于“航空公司”                相当于全球各个“航线目的地”          相当于包含所有航线的“电子客票”
 (如：光速云)                    (如：香港、日本、美国专线)          (一串由代码组成的专用网址)
                                                                     │
                                                                     ▼
                                                          【客户端 (飞机座舱)】
                                                           安装在手机/电脑里的软件
                                                           (如：Clash Verge 或官方自研端)
```

1. **机场**：提供翻墙服务的网站平台（比如你花钱购买套餐的商家）。
2. **节点**：部署在香港、日本、美国等机房里的服务器。你的网络流量通过它作为中转，从而成功访问海外网站。
3. **订阅链接**：一串特殊的专属网络链接。把它复制进软件里，软件就会自动下载并列出这家机场所有的节点。
4. **客户端**：运行在你电脑或手机上的工具软件（如 **Clash Verge Rev** 或 **光速云官方自研免配置客户端**）。它负责读取订阅链接，并帮你把流量加密发送到选定的节点上。

## 一、新手第一次出海的四大保姆级实操步骤

按照以下标准路径操作，可以确保你在 3 分钟内顺利连接全球互联网：

### 步骤 1：选购靠谱的主力机场套餐
- **避坑红线**：严禁购买任何不知名小作坊的超长大额年付套餐；
- **新手推荐**：选择运营超过 3 年的老牌专线品牌。例如**光速云 99 元/年（折合单月仅 8.25 元）**，或者轻度用户首选其 **¥147 元 247GB 永久不过期冷备用包**，彻底免去后续月租烦恼。

### 步骤 2：下载并安装适配的客户端软件
根据你的设备操作系统，选择对应的客户端：
- **Windows / macOS 推荐**：首选开源的 **Clash Verge Rev**；或者直接在光速云官网下载其 **官方自研客户端**（免去一切手动配置，登录即可使用）；
- **Android 安卓手机推荐**：下载 **Clash Meta for Android** 或光速云安卓专属 App；
- **iOS 苹果手机推荐**：需要使用非国区（如美区）Apple ID 登录 App Store，下载 **Shadowrocket（小火箭）**。

### 步骤 3：导入订阅链接并开启自动定时同步
1. 登录机场官网用户中心，找到并点击「一键导入 Clash」；若浏览器没有响应，点击「复制订阅链接」；
2. 打开客户端（以 Clash Verge Rev 为例），进入「Profiles / 订阅」页面，在上方输入框中粘贴链接，点击「Import（导入）」；
3. **关键细节**：右键点击刚导入的配置卡片，选择「编辑」，将**自动更新间隔（Update Interval）设置为 720 分钟（12小时）**，确保服务器维护更新时本地节点永不掉队。

### 步骤 4：正确选择节点与分流模式
1. 进入「Proxies / 代理」页面，展开节点列表，点击右上角「闪电图标」测试延迟；
2. 选择一个延迟较低的节点（日常网页和看剧推荐选择 **香港 (HK)** 或 **日本 (JP)**；使用 ChatGPT 请务必选择 **美国 (US)** 或 **新加坡 (SG)**）；
3. **分流模式务必选择「规则模式 (Rule)」**；
4. 点击主界面底部的「系统代理 (System Proxy)」开关，将其开启点亮。此时即可打开浏览器访问 Google、YouTube 等网站！

## 二、新手最常踩的五大“翻车陷阱”与黄金排障清单

刚接触科学上网的小白，遇到问题往往不知所措。以下五大常见故障及解决办法，能解决 99% 的日常求助：

### 陷阱 1：开启代理后，国内微信发不出图片、淘宝打不开了
- **原因**：误将客户端的分流模式设置成了「全局模式 (Global)」或「直连模式 (Direct)」；
- **排查解决**：在客户端主界面中，立即将模式切回「**规则模式 (Rule)**」。规则模式具备智能分流引擎，国内网站自动走本地直连，不仅速度极快且完全不消耗任何套餐流量。

### 陷阱 2：节点列表全是超时红字（Timeout / 9999ms），一个都连不上
- **原因 1：电脑或手机系统时间不准！** 现代加密通信要求客户端时间与服务器时间误差不能超过 60 秒，若时间偏差，SSL 握手会强制失败；
  - **解决**：进入 Windows「时间和语言」设置，点击「立即同步时钟」；
- **原因 2：机场官网的订阅节点变更了**；
  - **解决**：在客户端订阅卡片上右键点击「更新订阅」，拉取最新机房 IP。

### 陷阱 3：打开 ChatGPT 提示“Access Denied (Error 1020)”或“地区不支持”
- **原因**：OpenAI 官方目前**不支持中国香港 (Hong Kong) 地区**访问，如果当前连接的是香港节点，会被立刻阻断；
- **解决**：在节点列表中手动切换至**美国 (US)、日本 (JP) 或新加坡 (SG)**的专属解锁专线节点，并清除浏览器缓存重试。

### 陷阱 4：关掉代理软件后，电脑突然连百度都打不开了（网页显示无法连接代理服务器）
- **原因**：退出软件时异常闪退，导致 Windows 系统的代理注册表开关没有被正常还原，系统依然在向已经关闭的本地端口发送请求；
- **解决**：打开 Windows 设置 ->「网络和 Internet」->「代理」-> 找到「手动设置代理」，将**「使用代理服务器」开关手动关闭**，网页立刻恢复正常。

### 陷阱 5：在应用商店乱搜免费“加速器”，手机被流氓软件扣费
- **原因**：国内手机应用商店里的很多所谓免费 VPN，大多是套壳的扣费流氓软件，会偷偷扣除每周几十元的订阅费；
- **解决**：坚决卸载此类 App，只从 GitHub 官方仓库下载开源客户端，或使用老牌正规机场提供的官方自研安装包。
